# Linux System Health Monitor

A simple Bash script that checks and reports the health of a Linux system — CPU, memory, disk usage, internet connectivity, and more.

## Features

- Hostname and OS info
- System uptime
- CPU usage
- Memory (RAM) usage
- Disk usage
- Internet connectivity check
- Logged-in users
- Saves report to a log file (`health.log`)

## How to Run

```bash
chmod +x health_v2.sh
./health_v2.sh
```
